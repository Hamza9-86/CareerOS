# CareerOS

A personal job search management and job-market intelligence platform.

## Overview

CareerOS helps manage job applications, discover opportunities, analyze job-market trends, and understand application performance through a full-stack application and data engineering pipeline.

## Architecture

- **Frontend:** React, TypeScript
- **Backend:** Node.js, Express, TypeScript
- **Database:** MongoDB
- **Data Engineering:** Python
- **Data Storage:** JSON and Parquet
- **Analytics:** DuckDB, SQL
- **Infrastructure:** Docker

## Core Features

- Job application tracking
- Job discovery and bookmarking
- Job description analysis
- Application analytics
- Job market trends
- Automated data ingestion and transformation
